# Thunderobot L2

用一块 ESP32-C6，把雷神屏幕挂灯接进 Zigbee 网络。板子用蓝牙连灯，自己作为 Zigbee 终端设备加入协调器。Home Assistant 里可以开关、调亮度、调色温。

屏幕暂未点亮（暂无需求）。固件里留了在 1.9 寸屏上显示蓝牙和 Zigbee 连接状态的代码，目前不需要点亮。

这次只控制主灯。背面 RGB 的帧写在下面，没有做到 Home Assistant 里。

## 硬件

| 角色 | 设备 |
| --- | --- |
| 桥 | 微雪 ESP32-C6-LCD-1.9（ESP32-C6FH8，8MB 闪存，1.9 寸 ST7789，170×320） |
| 灯 | THUNDEROBOT L2，蓝牙名 `THUNDEROBOT L2` |
| 协调器 | Zigbee2MQTT。Home Assistant 通过 MQTT 发现设备 |

屏幕暂未点亮，下面的接线只是按这块板的出厂定义记下来，供以后要用时参考：SCK `GPIO5`，MOSI `GPIO4`，DC `GPIO6`，CS `GPIO7`，RST `GPIO14`，背光 `GPIO15`（低电平点亮）。

板子只有一颗射频。蓝牙扫描和 Zigbee 会抢无线电，所以只在没连上灯时短时间扫描，连上后停止扫描。不要把它配成 Zigbee 路由器。

## 蓝牙帧

服务 `0xFFF0`，写特征 `0xFFF3`，写类型是 Write Without Response。通知特征 `0xFFF4` 在这盏灯上没有出过数据。读 `0xFFF3` 得到固件版本字符串 `YG_P30_A28_V0031`，当前开关和颜色不从这里读。

帧长固定 9 字节，和宝莲灯（Lotus Lantern）/ ELK-BLEDOB 同一套：

```text
字节  0    1    2    3    4    5    6    7    8
     7E   LEN  CMD  P1   P2   P3   P4   P5   EF
```

| 字节 | 名称 | 作用 |
| --- | --- | --- |
| 0 | 起始 | 固定 `7E` |
| 1 | LEN | 长度标记。同一条命令里是固定值，按下面抄。它不是把后面几个字节加出来的校验 |
| 2 | CMD | 命令号，决定这一帧干什么 |
| 3–7 | P1–P5 | 参数。用不到的位置在现有帧里是 `FF` 或 `00` |
| 8 | 结束 | 固定 `EF` |

| CMD | 作用 | 这盏灯用的 LEN |
| --- | --- | --- |
| `05` | 颜色或色温。`P1` 再区分是 RGB 还是冷暖白 | 主灯 `06`，RGB `07` |
| `04` | RGB 开关 | `07` |
| `03` | 灯效 | `07` |
| `02` | 灯效速度 | `07` |
| `01` | RGB 亮度 | `04` |

下面标成「灯上确认」的字节，是改过数值、在这盏灯上看到变化的。标成「固定」的字节，发出去的帧里一直是这个值，没有单独改过；同系列应用的反编译和抓包也是这么填的。

### 主灯色温

`CMD = 05`，`P1 = 02` 表示两路白光。

```text
7E  06  05  02  CC  WW  FF  10  EF
起始 LEN CMD 白光 冷  暖  固定 固定 结束
```

| 字节 | 范围 | 作用 | 依据 |
| --- | --- | --- | --- |
| `CC` | `00`–`64` | 冷白 PWM | 灯上确认。`64 00` 冷白最亮，`14 00` 冷白变暗 |
| `WW` | `00`–`64` | 暖白 PWM | 灯上确认。`00 64` 暖白最亮 |
| 两路都 `00` | | 主灯灭 | 固件这样关。没有把这一帧单独再发一次 |
| `FF 10` | | 固定 | 没改过 |

两路各自独立，不必加起来等于 100。主灯变暗靠把 `CC`、`WW` 一起降低。`CMD = 01` 那条只改过背面 RGB 的亮度。

公开的宝莲灯反编译把 `P2 P3` 标成暖、冷，结尾写成 `08`。这盏灯按冷、暖来响应，结尾是 `10`。

固件把 Zigbee 色温（153–333 mired，约 6500K–3000K）和亮度（0–254）拆成 `CC`、`WW`。

### RGB 颜色

`CMD = 05`，`P1 = 03` 表示 RGB。要先发下面的开启帧，颜色才会上去。

```text
7E  07  05  03  RR  GG  BB  10  EF
起始 LEN CMD RGB 红  绿  蓝  固定 结束
```

`RR GG BB` 各 `00`–`FF`。灯上按红、橙、黄、绿、青、蓝、紫对过。最后的 `10` 固定；同系列协议里 `10` 表示普通设色，`20` 表示音乐幅度，这盏灯只发过 `10`。

### RGB 开关

`CMD = 04`。

```text
7E  07  04  SW  CH  01  02  01  EF
起始 LEN CMD 开关 通道 固定 固定 固定 结束
```

| 字节 | 值 | 作用 | 依据 |
| --- | --- | --- | --- |
| `SW` | `FF` | 开。灯里存着的灯效会接着播 | 灯上确认 |
| `SW` | `00` | 关 | 和一组停灯效的帧一起发出去的，没有单独再试一次 |
| `CH` | `00` | 我们实际发出的通道字节 | 灯上用过 |
| `01 02 01` | | 固定 | 没改过 |

同系列 LotusLamp X 抓包里，`CH = 01` 是只开 RGB，`CH = 02` 是只开冷白。这盏灯没试过这两个值。

### 灯效

`CMD = 03`。

```text
7E  07  03  XX  03  FF  FF  00  EF
起始 LEN CMD 灯效 类型 固定 固定 固定 结束
```

`XX` 是灯效号，灯上从 `87` 到 `9C` 共 22 档都看过。`P2 = 03` 在同系列协议里表示「灯效」；麦克风均衡用 `04`，这盏灯没改过这个字节。后面 `FF FF 00` 固定。

名称来自 ELK-BLEDOB / LotusLamp X，实灯表现和这张表一致：

| XX | 灯效 | XX | 灯效 |
| --- | --- | --- | --- |
| `87` | RGB 跳变 | `92` | 红绿渐变 |
| `88` | 七色跳变 | `93` | 红蓝渐变 |
| `89` | RGB 渐变 | `94` | 绿蓝渐变 |
| `8A` | 七色渐变 | `95` | 七色频闪 |
| `8B` | 红渐变 | `96` | 红频闪 |
| `8C` | 绿渐变 | `97` | 绿频闪 |
| `8D` | 蓝渐变 | `98` | 蓝频闪 |
| `8E` | 黄渐变 | `99` | 黄频闪 |
| `8F` | 青渐变 | `9A` | 青频闪 |
| `90` | 紫渐变 | `9B` | 紫频闪 |
| `91` | 白渐变 | `9C` | 白频闪 |

### 灯效速度

`CMD = 02`。

```text
7E  07  02  SS  FF  FF  FF  00  EF
起始 LEN CMD 速度 固定 固定 固定 固定 结束
```

`SS` 范围 `00`–`64`，灯上确认。后面四个字节固定。

### RGB 亮度

`CMD = 01`。

```text
7E  04  01  LV  01  FF  02  01  EF
起始 LEN CMD 亮度 模式 固定 固定 固定 结束
```

`LV` 范围 `00`–`64`，灯上确认能改背面 RGB 的亮度。紧跟着的 `01` 在同系列代码里叫 light mode，这盏灯没试过别的值。这条帧不改变主灯亮度。

## 编译和烧录

需要 PlatformIO Core 6.2 或更新。板子用 USB 串口，分区表是 Zigbee 终端设备那份 `zigbee.csv`。

```powershell
python -m platformio run
python -m esptool --chip esp32c6 write-flash --flash-size 8MB 0x10000 .pio\build\esp32-c6-devkitc-1\firmware.bin
```

只写 `0x10000` 上的应用，不会清掉已经保存的 Zigbee 网络。第一次烧录如果分区表还没写过，用 `python -m platformio run -t upload`。Windows 控制台如果因为进度条字符中断上传，改用上面的 esptool 命令。

长按 BOOT 三秒会清除 Zigbee 网络数据并重启，用来重新配网。

## 接入 Zigbee2MQTT

1. 协调器打开配网。板子入网后型号是 Thunderobot `L2`。
2. 把 [`zigbee2mqtt/thunderobot-l2.mjs`](zigbee2mqtt/thunderobot-l2.mjs) 存进 Zigbee2MQTT 的外部转换器。前端或 MQTT 都可以：

```text
主题 zigbee2mqtt/bridge/request/converter/save
{"name":"thunderobot-l2.mjs","code":"<文件内容>"}
```

3. 重新访谈这台设备。Home Assistant 里会出现一盏色温灯，实体卡片里有亮度条和色温条。设备页的控制区只放开关，点开灯泡那一行才能看到滑条。

如果设备曾经以别的固件入过网，协调器里会留着旧的端点。先从 Zigbee2MQTT 删除它，再长按 BOOT 三秒，打开配网后重新加入。
